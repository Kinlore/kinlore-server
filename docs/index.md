features:
  - title: One family per server
    details: You create the admin account in a web browser. Everyone else joins with an invitation link.
  - title: Roles and permissions
    details: Members are admin, partner or family. The admin turns adding content, commenting, liking and downloading on or off for each family member.
  - title: Five kinds of moments
    details: Photos, videos, stories, milestones from a list of 83, and growth records with height, weight and head circumference.
  - title: Original files kept
    details: The server keeps each photo and video exactly as it was uploaded, also HEIC photos from iPhones. Videos are converted for streaming in the background.
  - title: Look-back
    details: See "on this day" in earlier years, and "then and now" photos of each child.
  - title: Works offline
    details: The app keeps a local copy and syncs it with the server when it has a connection.
  - title: Full export
    details: The admin can download a ZIP file with all original photos and videos and all moments as JSON.
  - title: Docker or a plain Linux host
    details: Start the whole server with one Docker Compose command, or install it directly on Debian or Ubuntu.
