# What is Kinlore?

Kinlore is a family photo journal that you host yourself. "Host yourself" means that the server runs on a machine that you control: a computer at home, a small server, or a rented virtual server. Your photos do not go to a company.

Kinlore has two parts:

- **The server.** It stores the photos, videos and all other data. This site tells you how to install and run it.
- **The mobile app** for iPhone and Android. The family uses it to add and look at moments. See [Install the app](/app/install).

## One family per server

One Kinlore server holds one family.

- **One admin.** The person who installs the server creates the admin account in a web browser. See [Create the first admin](/self-hosting/first-admin).
- **Invited members.** Everyone else joins with an invitation link from the admin.
- **Shared data.** All members see all children and all moments.
- **A family name.** The server has a name, for example "Anna Example Family". Members see it in the app and on invitations. A stranger who finds the server address does not see it.

A family that wants a second, separate space runs a second server. The app can hold several servers. See [Several servers](/app/multiple-servers).

## Roles

Each member has one role:

| Role | What the member can do |
|---|---|
| `admin` | Everything. Only the admin manages members, invitations and exports. A server has exactly one admin. |
| `partner` | Add, edit and delete every child and every moment. Like, comment and download. |
| `family` | View everything. Add moments, like, comment and download only when the admin allows it. Edit or delete only their own moments and comments. |

## Moments

A moment is one memory of a child. Kinlore has five kinds:

- **Photo.** JPEG, PNG, GIF, WebP, HEIC or HEIF. The server keeps the original file and makes a small preview and a medium-size image.
- **Video.** MP4, MOV, M4V, AVI, MKV or WebM. The server converts it in the background to a stream in 720p, 480p and 240p.
- **Story.** A text.
- **Milestone.** One of 83 predefined milestones, such as a first step, with a date.
- **Growth record.** Height, weight or head circumference on a date.

One photo or video can be up to 500 MB.

## Other features

- **Likes and comments** on every moment.
- **Look-back.** "On this day" shows moments of the same day in earlier years. "Then and now" shows the earliest and the latest photo of each child.
- **Offline use.** The app keeps a local copy and syncs with the server later.
- **Duplicate check.** The app asks the server which phone photos are already uploaded.
- **Full export.** The admin downloads a ZIP file with all originals and all moments.
